# Dice Roller

Ein einfacher **Würfel-Generator im Browser**, entwickelt mit **HTML, CSS und JavaScript**. Dieses Projekt diente als Einstieg in die Welt der Webseiten.

Die Anwendung ermöglicht das Würfeln verschiedener Würfeltypen, wie z.B. in **Tabletop- oder Pen-and-Paper-Spielen (z.B. Dungeons & Dragons)** verwendet werden.

## Live-Demo

https://ksk9090.github.io/diceroll/

---

## Funktionen

* Würfeln mit verschiedenen Würfeltypen:

  * D4
  * D6
  * D8
  * D10
  * D12
  * D20
* Mehrere Würfe gleichzeitig möglich
* Anzeige jedes einzelnen Würfelergebnisses
* Automatische Anzeige der Gesamtsumme bei mehreren Würfen
* Einfache und übersichtliche Benutzeroberfläche
* Würfel-Soundeffekt beim Würfeln

---

## Funktionsweise

1. Wähle den gewünschten Würfeltyp (z.B. D6 oder D20).
2. Gib die Anzahl der Würfe ein.
3. Klicke auf **„Let it rip!“**.
4. Die einzelnen Ergebnisse sowie die Gesamtsumme werden angezeigt.
